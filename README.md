# Учебный frontend-проект

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта
- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `sitemap.xml` — карта страниц для поисковых систем;
- `css/style.css` — файл стилей;
- `js/main.js` — обработка формы заявки;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## CSS-архитектура
- Цвета, отступы, ширина контейнера и скругления заданы CSS-переменными в `:root`.
- Ссылки, кнопки, карточки и поля формы имеют состояния наведения; для клавиатуры видны фокус и отключённое состояние.
- Flexbox используется для навигации и структуры карточек; Grid — для сетки товаров и каталога.

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке.

## Использование Flexbox и Grid
- Flexbox выравнивает основное меню и содержимое карточек товаров.
- CSS Grid размещает популярные товары в сетке и делит каталог на фильтры и список товаров.
- Фильтры передают выбранные значения через параметры URL методом GET.
