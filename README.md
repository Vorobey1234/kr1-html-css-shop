# Учебный интернет-магазин

Многостраничный сайт интернет-магазина для практических занятий по дисциплине «Фронтенд и бэкенд разработка». Тема проекта — каталог товаров с карточкой товара и формой оформления заявки.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

## Страницы и структура

- index.html — главная страница с преимуществами, товарами и модальной формой;
- catalog.html — каталог со статическим блоком фильтров, карточками и модальной формой заказа;
- product.html, product-2.html, product-3.html — отдельные страницы трёх товаров с характеристиками и ценой;
- order.html — отдельная форма оформления заявки;
- contacts.html — контактная информация;
- css/style.css — стили, CSS-переменные, Flexbox, Grid и BEM-компоненты;
- js/main.js — обработка модальной формы, валидация и сообщение об отправке;
- images/ — иллюстрации трёх товаров;
- sitemap.xml — карта страниц;
- .gitignore — исключения Git.

## Технологии

HTML5, CSS3, JavaScript, Git, GitHub Pages.

## Реализованные требования

- Семантическая разметка и общая навигация по страницам.
- Сетка товаров на CSS Grid и компоненты на Flexbox.
- BEM-блоки: site-header, site-nav, breadcrumbs, hero, products-grid, product-card, catalog-layout, catalog-filters, order-dialog, order-form, button, site-footer.
- Таблица характеристик товара с подписью, заголовком и данными.
- Форма заявки с полями имени, e-mail, телефона, темы, товара, комментария и согласия.
- CSS-переменные, позиционирование relative/absolute/sticky, состояния наведения и фокуса.

Категории и поля цены «От/До» в каталоге — статическая разметка из практической работы №6. Она не отбирает и не сортирует товары: в №8 проверяется именно такой блок. Модальная форма и её базовая валидация относятся к работе №3.
